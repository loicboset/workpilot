# review

The weekly review, for now a look back: the notes of the last 7 days (today included, in the
profile's timezone), newest first. The homepage card lists them after their day and time and
scrolls; the page groups them by day and shows them in full. The review's time on the card
("Friday · 16:30") is still placeholder data (`features/home/demoData.ts`); journal entries and
review templates come with v0.2.

# 0016. AI in v0.1: foundation + ticker

- Status: Accepted
- Date: 2026-09-27

## Decision

v0.1 includes the AI foundation (one provider interface for a cloud API or a local model, one editable prompt) and one AI feature: the ticker (insights and tips from Today and Direction data; static tips as offline fallback). Offline sync stays in v0.1.

## Why

Proves the expensive-to-change AI interface early with a low-risk feature.
